# 2026-04-27

## 機能追加: /admin/cron-status ステータスページ

Vercel Cron ジョブの稼働状況を可視化する公開ステータスページを新設した。

### 内容

- **ページ**: `/admin/cron-status` (公開・noindex・SSR・F5更新)
- **対象ジョブ**: `sync-events`、`sync-lapcenter`
- **表示**:
  - ジョブ別カード（最終実行時刻 / ステータス / 実行時間 / 健康判定バッジ）
  - 履歴テーブル（直近30件、result jsonb から主要メトリクスを1行サマリ）
  - KPI時系列グラフ（recharts、events.count / lapcenter.matched / new_matches / tracked_runners）
- **健康判定**: 緑（24h以内success）/ 黄（24-48h or deploy.triggered=false）/ 赤（48h超 or 直近error or 水曜なのにdeploy/runners=null）
- **水曜判定**: 直近水曜の指定実行時刻（events=03:00、lapcenter=12:00）以降の最新成功実行を見て、deploy/runnersが入っているか確認

### Resend通知（Cronエラー時）

- `logCron()` で `status='error'` を記録した時、Resend経由でメール送信
- 同じ `(job_name, error_signature)` は **24h以内 1通までデダブ**
- 失敗時は console.error のみで Cron 本体に例外を投げない

2. **Vercel環境変数追加** (Production + Preview):
