## Cron安定稼働復旧
- **根本原因**: 3/9 のセキュリティ修正で `CRON_SECRET` 必須チェックを追加したが、Vercel 環境変数に未登録 → 両 Cron が 500 で即死（2週間未検知）
- `CRON_SECRET` を Vercel 環境変数に登録 → 両 Cron 復旧
- Vercel Deployments API → **Deploy Hook** に簡素化（`VERCEL_DEPLOY_HOOK` 環境変数）
  - 不要になった環境変数: `VERCEL_PROJECT_ID`, `GITHUB_ORG`, `GITHUB_REPO`
- `cron_log` テーブル（Supabase）で Cron 実行ログを記録（稼働監視用）
  - `src/lib/cron-logger.ts` 新規作成
  - `sync-events/route.ts`, `sync-lapcenter/route.ts` にログ記録追加
- `.github/workflows/scrape-lapcenter.yml` 削除（PAT scope 不足で未 push、sync-lapcenter と重複）

## ランキング自動更新（PC不要化）
- **問題**: Vercel ビルド環境から JOY への直接 curl が失敗 → ランキング JSON が古いまま
- **解決**: Proxy API (`/api/rankings/proxy`) 経由でビルド時に取得
  - Serverless Function 環境から JOY へは正常アクセス可能（sync-events で実証済み）
  - ビルド中は前回デプロイの API が生きているため、プロキシ経由で取得可能
  - フォールバック: プロキシ失敗 → JOY 直接 fetch → ローカルファイル
- `scripts/build-analysis-index.ts`: `execFileSync("curl")` → `fetch()` + Proxy に変更、async 化
