# 2026-04-01 作業ログ

## LapCenter イベントマッチング精度向上

筑波大大会（Day1/Day2）がLapCenterと自動紐づけされない問題を調査・修正。

### 原因
- events.json: `第45回筑波大大会 Day1`
- LapCenter: `第45回筑波大学オリエンテーリング大会 Day1`
- normalize後のコア文字列が「筑波大」(3文字) vs 「筑波大学」(4文字) となり、`cShorter.length >= 4` の閾値を満たさずマッチ失敗

### 対応内容 (`src/lib/scraper/lapcenter.ts`)

1. **大学略称展開 (`UNIVERSITY_ALIASES`)**: 21大学の略称→正式名称マッピングを `normalize()` に追加
   - 筑波大→筑波大学、新大→新潟大学、神大→神戸大学、金大→金沢大学 等
   - `(?!学)` で既に正式名称の場合はスキップ

2. **イベント名略称展開 (`EVENT_ALIASES`)**: 頭字語・略称の展開
   - BMO→忘年マウンテンオリエンテーリング
   - OMO→奥武蔵マウンテンオリエンテーリング
   - MAMM→南アルプスマウンテンマラソン
   - スプセレ→スプリントセレクション
   - インカレ→日本学生選手権

3. **表記揺れ正規化**: ウエ→ウェ

4. **コア文字列閾値緩和**: `cShorter.length >= 4` → `>= 3`

### 結果
- 手動sync-lapcenter実行で **44件の新規マッチ** (868 → 912)
- 766件のランナーデータ（巡航速度・ミス率）を新規取得
