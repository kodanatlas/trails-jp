# 作業ログ 2026-03-11

## 実施内容

### 1. Supabase Security Advisor 脆弱性修正

**問題**: 3テーブルの RLS ポリシー「Service role can manage ...」が `roles={public}` で設定されており、anon key で誰でも INSERT/UPDATE/DELETE 可能な状態だった。

**調査結果**:
- `athletes`, `athlete_appearances`, `lc_performances` の ALL ポリシーが危険
- `likes` の INSERT ポリシーが無制限
- 全 API Route は `supabaseAdmin` (service_role key) を使用しており、RLS バイパスのためアプリ動作に影響なし

**修正内容**:
1. 危険な ALL ポリシー3件を削除（service_role は RLS バイパスするため不要）
2. `likes` の INSERT ポリシーを `authenticated` ロールのみに制限
3. SELECT ポリシーは全テーブルで維持（anon key での読み取りは引き続き可能）

**適用方法**: `supabase db push` でマイグレーション適用済み

### 2. Supabase CLI 連携設定
- `SUPABASE_ACCESS_TOKEN` を `.env.local` に追加
- `supabase link` でプロジェクト連携設定
