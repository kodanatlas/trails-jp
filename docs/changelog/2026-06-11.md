## 環境メモ（重要）

- **ビルドは Git Bash + Windows node に逆転**（node_modules が Windows install になり、WSL Linux node は lightningcss native 不足で `next build` 不可）。
- WSL 非対話 `bash -lc` は nvm 未ロード→ PATH interop で Windows npx が呼ばれ **WSL の env 変数が渡らない**（SKIP_FETCH が消えて JOY フル再取得が走る事故が発生、git restore で復旧）。
- `vercel curl` は Git Bash の MSYS パス変換で `/a/...` が `C:/Program Files/Git/a/...` に化ける → `MSYS_NO_PATHCONV=1` 必須。
- Supabase env は Vercel の **Production のみ**登録（preview では likes API 500・snapshot 書き込みスキップ）。
