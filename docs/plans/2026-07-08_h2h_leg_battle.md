# H2H レッグ勝敗（同一クラス＝同一コースの区間タイム比較）

- 作成: 2026-07-08 JST / ステータス: 実装完了（本番確認は PR マージ後）
- 発端: 専門読者レビュー第2弾「あいつに勝った/負けたレッグまで見たい」（第2弾で保留→今回実装）

## 設計判断（当初案から改良）

当初案は `/api/lc-split` で mulka2 を都度取得だったが、**`lc_leg_splits` に全走者の区間タイムが既にある**ため、外部依存なしの新 API で直接読む方式に変更（高速・レイテンシ無し）。両者は tracked 選手なので共通の同一クラスレースは取込済み。

**重要な制約**: レッグ勝敗は「同じコース＝同一クラス」でのみ意味を持つ。同じ大会でも別クラス（別コース）は比較不能なので、**同一 (lc_event_id, lc_class_id) に両者が居るレースのみ**対象。得点ベースの勝敗（従来）は全対戦で出る。

## 実装

- 純ロジック `src/lib/analysis/leg-h2h.ts`: `buildLegH2H(rows, keyA, keyB)`。(event,class) で両者を突合し、レッグ毎に `lap_sec` を比較（速い方が勝ち・null/非正は除外）。レース別＋総計。テスト6件。
- API `src/app/api/h2h-legs/route.ts`: `?a=&b=` → runner_key で lc_leg_splits を引き buildLegH2H。1h キャッシュ。
- UI `HeadToHead.tsx`: 相手選択時に fetch し、**同一クラスで対戦したレースがある場合のみ**「レッグ勝敗 ○勝○敗（共通N レース・M レッグ）」＋レース別内訳を表示。
