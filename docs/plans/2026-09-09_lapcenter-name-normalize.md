# LapCenter × JOY 名前正規化の修正（2026-09-09）

ブランチ `fix/lapcenter-name-normalize`。対象は `src/lib/scraper/lapcenter.ts` と
`src/lib/scraper/__tests__/fuzzy-match.test.ts`。

## 直した不具合

1. **裸の西暦が消えない**。`normalize` は `20\d{2}年度?` を落とすが `20\d{2}` を落として
   いなかった。LC「霧ヶ峰ミドルオリエンテーリング2025」の core が「霧ヶ峰2025」になり、
   JOY「霧ヶ峰ミドルO」と一致しなかった。`src/lib/analysis/event-match.ts` の
   `stripEventNoise` は裸の西暦も落としており、こちらだけ揃っていなかった。
2. **STOP_WORDS の除去順**。`coreString` が Set の宣言順で消すため短い語が長い語を食う。
   `"OL"` が `"OLC"` を、`"日本"` が `"日本代表"` を食っていた。

## 2 層目の原因（両方が同じ壁に当たる）

どちらの修正も `fuzzyMatch` の **core 比較の 3 文字下限**に突き当たる。ノイズを消すほど
core が痩せ、下限を割って比較そのものが走らなくなる。

- 西暦を消すと「岩手大会2025 Day1」の core は `岩手2025` → `岩手`（2 文字）。相手の
  `岩手スプリント` と包含関係があるのに弾かれ、**岩手・菅平・沖縄・新潟の Day 系 17 件**が
  新たに未突合になる（2025・2026 実データ計測）。西暦は識別に寄与しない詰め物として
  下限を通していただけだった。突合は同日限定なので西暦に識別力はない。
- 同じ理由で「大阪OLC」は除去順を直しても core が `大阪` の 2 文字になり一致しない。

したがって **下限を 3 → 2 に下げる**ところまでを 1 セットとした（`full1`/`full2` の 4 文字
下限とトライグラムの 5 文字下限は据え置き）。

## 全期間ゲート（2019–2026）

`src/data/events.json` の 2272 件（うち 858 件が `lapcenter_event_id` 済み＝正解データ）と
mulka2 から実取得した LC 2536 件で、`matchLapCenterEvents` を修正前後で実行して比較した。

- **既存リンクの付け替え: 0 件**
- **張られなくなったリンク: 0 件**
- 新たに張られたリンク: **+78 件**（リンク総数 970 → 1048）
- 78 件を目視。明らかな誤マッチ 0 件。要確認 2 件＝ WMG プレ大会の 一般/マスターズ と
  LC の 予選/決勝 の対応、MAMM の 3 部門のうちどれに張るか（後者は元からの制約）

`fuzzyMatch` 単体をゼロから割り当て直す測り方では付け替えが 3 件出るが、本番は
`usedLcIds` に既存リンクを先に予約してから未突合だけを埋めるため発生しない。

## `MANUAL_LC_NO_MATCH` の役割追加

下限緩和の代償として同日別レースへの誤当たりが増えうる。この定数は `match-gaps.ts` の
突合漏れ検知のミュートにしか使われておらず、「LC に結果が出ない大会」と分かっていても
自動突合を止める手段がなかった（`MANUAL_LC_OVERRIDES` は正しい LC id を持つ大会にしか
使えない）。`matchLapCenterEvents` でも参照し、**既存リンクは保持したまま新規の自動突合
だけ**を抑止するようにした。

## 残課題

`fuzzyMatch` は同日候補の**最初の一致**を採るため、2 文字 core の弱い包含一致が、より
適切な候補を押しのけうる（例: `fuzzyMatch("岩手大会2025 Day1", "岩手大学新人練習会")` は
修正後 true）。2019–2026 の実データでは発生していないが、候補を全部評価して一致の強さで
選ぶ形にするのが本筋。別スコープ。

## 再現方法

LC イベント一覧は `fetchLapCenterEvents(year)` を 2019–2026 で回して取得できる。ゲートは
使い捨てスクリプトで実施したためリポジトリには残していない。
