# 対戦成績カード: 相手名から相手の選手ページへ遷移

ステータス: 完了（2026-09-30 main へ push）

## 目的
選手ページの対戦成績（Head-to-Head）カードで相手を選んだ後、相手選手のページへ直接移動できるようにする。

## 仕様（ユーザー確認済 2026-09-30）
- リンクにするのは **勝敗サマリ右側の相手名のみ**（履歴表の列見出しは幅 w-14 で truncate されるため対象外）
- 遷移先は正規 URL `/a/<空白除去名>`、`next/link` で **同一タブ**（サイト内の他の選手リンクと同じ）
- 押せることが分かるよう、下線（accent/40）＋ `ArrowUpRight` アイコンを付ける

## 変更
- `src/app/analysis/HeadToHead.tsx` のみ

## 検証
- `tsc --noEmit` / `eslint`: エラー 0
- `/a/[name]/page.tsx` は decode → 空白除去 → `athleteIndex.athletes[key]` で解決することを確認
- 実ブラウザ（WSL dev・Chrome）: /a/宮本樹 で相手=用松知樹を選択 → 相手名（下線＋↗）を実クリック → /a/用松知樹 へ同一タブ遷移。
  ブラウザ「戻る」で /a/宮本樹 に戻り、対戦成績カードは未選択（候補チップ）状態に戻る

## 追加修正: 「戻る」で元の画面に戻らない（2026-09-30 ユーザー報告・スマホ）
- 症状: 相手名リンクで移動 → 戻る で、相手選択が消える／分析ハブ経由で開いた選手は分析トップが出る
- 原因: ①相手選択がどこにも残らない ②ハブは選手選択時に URL だけ `/a/<key>` に replaceState しており、
  戻りでハブが再マウントされても `?athlete=` しか見ないため選手を開き直せない
- 修正:
  - `HeadToHead.tsx`: 相手選択を `?vs=<key>` に同期（解除で削除）、初期表示で `?vs=` から相手を復元
  - `AnalysisHub.tsx`: 初期化時にパス `/a/<key>` からも選手を開く（URL は正規化せず `?vs=` を保持）。解除時は `vs` も削除
- 検証（WSL dev・Chrome）: ハブ検索経由／`/a/` 直開きの両経路で、戻る → 相手選択済み（9勝4敗0分）で復元。
  直開きはスクロール位置も維持（1854px）。「相手を変更」で `?vs=` が消える。tsc / eslint エラー 0
- スマホ実機: 本番デプロイ後にユーザーが確認済（2026-09-30）
