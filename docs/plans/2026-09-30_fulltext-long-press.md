# 省略表示（…）された文字を長押しで全文表示する

- 作成: 2026-09-30 JST
- ステータス: **完了**（試験導入・PR #80 本番反映 2026-09-30。本番でヘッドレス Edge のタッチ操作を確認済み。実機での使い心地の確認はユーザー手動タスク）

## 目的
スマホで長い文字が「…」で省略されると全文を読めない。軽い操作で全文を見られるようにする（ユーザー要望 2026-09-30）。

## 決定事項（ユーザー確認済み）
- **長押しで、文字の上に吹き出し（ポップオーバー）で全文を出す**。PC はマウスを乗せると全文のツールチップ
- **2 行表示（リンクを折り返す案）はやらない**
- **不便なら戻せるようにする**: `src/lib/ui-flags.ts` の `FULLTEXT_ON_LONG_PRESS` を `false` にすると、全画面が従来の省略表示だけに戻る（長押ししても何も起きない）。PR 単位の revert でも戻せる
- 対象: 公開画面すべて。`_tracking`・`_maps`・配車割（`carpool`）は対象外

## 仕様
- 共通部品 `src/components/FullText.tsx`。省略表示していた要素（`truncate`）をこれに置き換える（タグ・クラス・style はそのまま）
- **実際に省略されているときだけ反応**（`scrollWidth > clientWidth`）
- タッチで約 0.45 秒押し続けると吹き出し。指が 10px 以上動いたらスクロールとみなし取り消す
- **リンクの中・リンクの外側のどちらでも、長押しの後のタップでページ移動しない**（捕捉フェーズで `preventDefault`＋`stopPropagation`。Next の Link は `defaultPrevented` を見て移動しない）。普通のタップは従来どおり移動
- リンク・ボタンの中でない文字は、普通のタップでも吹き出しを出す
- 吹き出しは、ほかの場所のタップ・スクロール・画面サイズ変更で閉じる。基本は文字の上・中央揃え、上に入らなければ下。画面端から 8px 空ける
- 省略された文字の上では、iOS の長押しメニュー（`-webkit-touch-callout: none`）・Android の長押しメニュー（`contextmenu`）・長押しでの文字選択（タッチ端末のみ `select-none`）を出さない。PC では選択・コピーできるまま
- `fullText` で吹き出しの文字を指定できる（例: 区間賞ボードの「名前（クラブ）」。元の `title` の代わり）

## 実装
- 画面に依存しない判定を `src/lib/ui/long-press.ts` に分離（長押しの判定・吹き出しの配置）。テスト 7 件
- 置き換え: 16 ファイル（トップの更新情報・今週の応援・週末ハイライト・今月の上昇、ランキング、イベント一覧、結果分析の一覧・レッグ分析、選手ページ、対戦成績、比較、クラブ、応援、分析ハブ、エントリー、ミスの傾向の一覧）
- 置き換えなかったもの: 実際には省略されていない要素（インラインの `span` に `truncate` が付いているだけのもの）、省略の実体が内側の要素にあるコンテナ

## 検証
- vitest 982 件緑・tsc 0・lint は変更ファイルで main と同数（新規エラーなし）
- ヘッドレス Edge（390px・タッチ・CDP で長押しを再現）:
  - トップの更新情報（リンク）: 長押しで全文の吹き出し（画面内）・ページ移動しない・ほかをタップで閉じる・普通のタップで `/analysis` へ移動
  - ミスの傾向の一覧のレース名（ただの文字）: 普通のタップで全文の吹き出し
  - 省略されていない文字（選手名）: 長押ししても何も出ない
- 実機（iPhone / Android）での確認は本番反映後にユーザーが行う
